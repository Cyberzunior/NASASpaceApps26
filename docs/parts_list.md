# Parts (short version; the full list with costs is in docs/)
**HUD panel (UNO Q):** LCD1602, I2C OLED SSD1306, joystick module, green / blue / red / yellow LEDs with 220 ohm resistors, passive buzzer.

**Tower (ELEGOO UNO R3):** 28BYJ-48 + ULN2003 (yaw), green laser module, 2N2222 + base resistor, HC-SR04, SG90 (pitch servo),
optional test button, second MB102 supply module.

**Rover (UNO Q):** 2 TT motors + 2 wheels (65 mm), caster or skid, 1 dual DRV8833 module, 28BYJ-48 + ULN2003 (camera pan),
Logitech C920, MB102 supply module set to 5 V + 9 V battery, optional bumper buttons, status LED.

**Also:** breadboards, jumper wires, 2 USB data cables for the laptop, Bluetooth gamepad (optional), cardboard, tape, zip ties, hot glue, velcro.
