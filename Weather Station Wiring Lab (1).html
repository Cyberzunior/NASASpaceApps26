Weather Station Wiring Lab

UNO R3 + 16-pin LCD + DHT11 + 4 LEDs + 2 buzzers. Build it step by step, then test it live. Drag to rotate, scroll to zoom, tap any wire or part for details.

Step 1

Live simulation

This runs the same rules as weather_station.ino v2. Change the temperature and watch the LEDs, buzzers and LCD react.

Too low and the LCD shows only a blue block, with no text. Too high and it shows dark squares. That is exactly what you saw. Turn the real pot slowly until the letters appear.

Serial monitor (115200)

Hot: above 30°C. Cold: below 18°C. It goes back to normal only after 1°C of margin (29°C and 19°C), so it does not flicker.

If something does not work

Red LED never lights

First, it only lights in HOT mode. Type V,35 in the Serial Monitor (115200, Newline). Also watch the start-up self-test: red flashes once.

  1. LED backwards? The long leg (anode) goes to the resistor side, the short leg to GND.
  2. Is the resistor in the same strip as the D5 wire?
  3. D5 wire one hole off? D4 is blue, D6 is the buzzer.
  4. Test the LED alone: move its resistor wire from D5 to 5V. If it lights, the LED is fine.
Active buzzer is silent
  1. Peel the sticker off the top.
  2. It only sounds in HOT mode (V,35) and in the self-test.
  3. PN2222 flat face toward you, legs down: left is E (emitter, to GND), middle is B (base, from D6 through 1 kΩ), right is C (collector, to the buzzer minus).
  4. Buzzer plus (long leg) goes to 5V.
Passive buzzer is silent

It makes sound only when the code plays a tone. That happens in COLD mode (V,10) and in the self-test. Plus goes to D7, minus to GND.

LCD shows only a blue block
  1. Turn the contrast pot slowly. Use the Simulate tab to see what each setting looks like.
  2. Check pin 5 (RW) goes to GND. If RW floats, the LCD can stay blank.
  3. Check RS to D8, E to D9, D4 to D10, D5 to D11, D6 to D12, D7 to D13.
LCD says SENSOR ERROR

The DHT11 data wire (S) must go to D2, plus to 5V, minus to GND. Labels on the module matter more than the pin order shown here.

Arduino IDE: DHT.h: No such file or directory

Open Library Manager and install DHT sensor library (Adafruit) and Adafruit Unified Sensor, then press Verify.

Quick test commands

Serial Monitor at 115200 baud, Newline: V,35 hot, V,10 cold, V,24 normal, H,14 hit flash, G game over, R restart.
